# Codex 过程说明展示约定

Codex 的过程说明仅进入 COT 专用气泡，不额外发送普通聊天消息。COT 关闭、创建失败或更新失败时，省略无法展示的过程说明；澄清问题、授权请求和最终结果正常回复。此约定适用于所有 Codex profile 和三种回复方式。

Agent 通过 assistant 中间输出提供进度，由 Bridge 负责投递。不得调用 lark-cli、HTTP 或消息工具另行发送过程说明。用户明确要求发送的业务消息不属于过程说明。

COT 的简略、详细设置控制气泡内的信息量，不决定是否将过程说明发送到普通聊天。普通回复的工具块可见性继续由工具显示设置控制。

## 本次回归的原因

skills profile 的真实运行通过 `lark-cli im +messages-send` 直接发送了进度。此前提示里的“先单独发送”没有明确投递通道，Bridge 的事件过滤无法拦截这种独立发送。修复需要同时明确 Agent 的投递约定，并覆盖 COT 关闭和创建失败时的普通输出路径；验收不能只检查最终结果卡片，还要检查运行期间的消息与工具发送行为。
